# IdeaVault

### – Startup Idea Sharing Platform

---

IdeaVault is a full-stack web application where users can share startup ideas, explore creative ideas from other users, and interact through comments and discussions. The platform creates a collaborative environment where people can validate ideas, give feedback, and improve concepts together. Users can easily discover innovative startup solutions in different categories and engage with the community in a modern and user-friendly interface.
The project focuses on creativity and idea sharing. It also provides secure authentication, protected routes, responsive design, and smooth user experience across all devices.

---

### Features

- User authentication with Email/Password and Google Login
- Add, update, and delete startup ideas
- View all ideas in a responsive card layout
- Comment system with edit and delete functionality
- Personal dashboard for My Ideas and My Interactions
- Fully responsive design for mobile, tablet, and desktop devices
- search functionality from backend

---

### Technology Used

- JavaScript
- Next.js
- Tailwind CSS
- HeroUI
- React Swiper
- Better Auth
- MongoDB

#### This is a modern full-stack project built with a clean UI, protected routes, dynamic pages, and interactive user features.
